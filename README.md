\# YouTube Video Summarizer



A Python application that extracts YouTube video transcripts and generates concise summaries using the DistilBART model.



\## Features

\- Extract YouTube video transcripts

\- Generate concise summaries

\- Display complete transcripts

\- Download generated summaries

\- Download transcripts



\## Technologies Used

\- Python

\- Hugging Face Transformers

\- DistilBART

\- PyTorch

\- Gradio

\- YouTube Transcript API
